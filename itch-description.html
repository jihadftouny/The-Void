The Void

Early prototype — work in progress.  GitHub

A text-based, turn-based RPG built on Dungeons & Dragons–style mechanics. It's a prototype for exploring LLM-driven content: enemies, lore, and story generated at runtime instead of hand-written.

What's in it

  • D&D-style attributes (STR, DEX, CON, INT, WIS, CHA) with dice-based, turn-based combat
  • Equipment with a rarity system — armor, weapons, trinkets, usables
  • Skills and status conditions
  • Random encounters — battle, shop, rest
  • Randomly generated enemies with mixed ability sets and loot
  • Four floors / four acts, ending in a final boss

Where the AI comes in

The direction is to hand content generation to an LLM — spawning enemies, writing lore, and driving the story on the fly, layered on top of the dice and stat systems that already run the game. That part is still early.

Rough and changing often. Feedback welcome.
