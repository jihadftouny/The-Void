## The policy

**Shown at the start of every fresh run — not only the first.**

> Author's direction: *"not only the first run, every run where we start from scratch."*

- **Every new descent** shows it, before anything else. Not a one-time first-launch gate that a
  player clicks past and never sees again.
- **Not** shown when *resuming* an existing run — you already saw it when that run began.
- **It must be dismissible**, not a timed lock. Respect for the player is the point.
- The same words appear on the **itch store page** and in the **README**, so nobody meets the game
  cold — including someone handed it by a friend or launching it from the itch app.

**Why every run, and not once:** a roguelike is played in sessions across weeks. A warning seen once
in March is not a warning in June. And because the descent restarts, the warning restarting with it
is structurally honest — you are choosing to go down again, each time.

## What it should say **[the author writes this]**

Guidance, not text. **This must be in the author's own voice, not legal boilerplate** — the game is
built from lived experiences, and a clinical disclaimer would undercut the thing it introduces.

Worth covering:
- **What the game is about**, plainly.
- **Who wrote it and why** — that it comes from lived experience.
- **That it is a survivor's story**, not a nihilism piece. `docs/WORLD.md` §6 makes this structural:
  the angels on floor 4 are *real*, grace is genuine mercy, and the good ending is *made whole*. The
  warning should carry that, so it frames the game rather than apologising for it.
- **A line for anyone who should not play it right now**, without condescension.

**Do not** enumerate mechanics as content descriptors ("contains depictions of…"). The design's own
rule is that the theme is never named or metered inside the game (`GAME-DESIGN.md` §13); the warning
is the one place it is spoken plainly, and it should sound like a person, not a label.
